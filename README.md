# weather-app

Application meteo mobile geolocalisee, en React Native.

## Composants

`CurrentWeather` (conditions actuelles), `ForecastList` et `ForecastItem` (previsions),
`Loader` (etat de chargement).

La position de l'appareil est obtenue via `expo-location`.

## Stack

Expo, React Native, `expo-location`.

## Lancer

```sh
npm install
npm start
```

`npm run android`, `npm run ios` ou `npm run web` pour cibler directement une plateforme.
